JACE · KAKAO DAILY SETUP

매일 낮 12시,
내 코인 현황을 카카오톡으로.

수신처는 본인 카카오톡의 나와의 채팅입니다. 최초 연결을 마치면 PC와 대시보드를 닫아도 예약 발송 서버가 시세를 조회해 보고서를 보냅니다.

현재는 연결 준비 단계입니다.
카카오 개발자 앱과 보고서 서버를 설정하기 전에는 실제 자동 발송이 실행되지 않습니다. 아래 준비를 마친 뒤 대시보드의 시작 버튼으로 활성화하세요.

1. 카카오 개발자 앱 만들기

  1. Kakao Developers에 본인 카카오 계정으로 로그인하고 앱을 추가합니다. 예: JACE 코인 리포트.
  2. 카카오 로그인을 활성화하고, 동의 항목에서 카카오톡 메시지 전송(talk_message)을 설정합니다. 본인 앱의 소유자 계정으로 연결합니다.
  3. 웹 도메인으로 https://jacelee660303-png.github.io를 등록합니다. 메시지의 대시보드 버튼에 사용하는 도메인입니다.
  4. 앱의 REST API 키와 사용 설정된 클라이언트 시크릿을 확인합니다. 대화나 공개 GitHub에 올리지 말고 아래 서버 비밀 설정에만 입력합니다.

카카오 공식 로그인 설정 안내 ↗ · 나에게 메시지 보내기 안내 ↗

2. 보고서 서버 연결 준비

이 앱의 공개 화면은 GitHub Pages에서 제공됩니다. 브라우저가 닫힌 뒤에도 예약을 실행하고 카카오 인증 정보를 보관하려면 별도의 서버가 필요합니다. 함께 제공된 Cloudflare Worker가 이 역할을 맡습니다. Cloudflare 계정에 배포하면 서버 주소가 생깁니다.

서버를 설치하는 상세 절차

Node.js와 Cloudflare 계정이 있는 PC에서 실행합니다. 계정의 이용 한도·요금은 Cloudflare 대시보드에서 확인하세요.

git clone https://github.com/jacelee660303-png/pension-dashboard.git
cd pension-dashboard/crypto/kakao-worker
npx wrangler@4 login
npx wrangler@4 deploy

배포가 끝나면 출력되는 https://jace-crypto-report.…workers.dev 주소를 기록하세요. 다음 명령을 실행한 뒤 요청받을 때 각각의 값을 입력합니다. 명령줄에 실제 키를 직접 붙이지 마세요.

npx wrangler@4 secret put KAKAO_REST_API_KEY
npx wrangler@4 secret put KAKAO_CLIENT_SECRET
npx wrangler@4 secret put REPORT_ADMIN_KEY

KAKAO_CLIENT_SECRET은 카카오 앱에서 사용 설정된 경우 입력합니다. REPORT_ADMIN_KEY에는 비밀번호 관리자에서 생성한 32자 이상의 무작위 비밀 문자열을 입력합니다. 이 관리 키는 대시보드에서 본인 서버를 제어할 때도 사용하므로 안전하게 보관하세요.

설정 파일에 매일 UTC 03:00(한국시간 12:00) 예약이 포함되어 있습니다. 설정 변경은 전파에 시간이 걸릴 수 있습니다. Cloudflare 예약 실행 안내 ↗

3. 카카오 로그인으로 연결하기

  1. 카카오 앱의 로그인 Redirect URI에 보고서서버주소/oauth/callback을 정확히 등록합니다. 예: https://jace-crypto-report.example.workers.dev/oauth/callback.
  2. 대시보드의 카카오 데일리 → 연결 설정에 서버 주소와 연결용 관리 키를 입력합니다. 카카오 앱 키를 넣는 칸이 아닙니다.
  3. 카카오 계정 연결 → 카카오 로그인 계속을 눌러 본인 계정으로 로그인하고 메시지 전송에 동의합니다.
  4. 완료 창을 닫고 대시보드에서 연결 상태 확인을 누릅니다. ‘카카오 연결됨’ 표시를 확인하세요.

4. 기간을 정하고 발송 시작

  1. 잔고와 평균 매수가를 입력하고 저장합니다.
  2. 발송 시작일과 종료일을 설정합니다. 두 날짜 모두 발송 기간에 포함됩니다.
  3. 자동 발송 시작을 누릅니다. 서버가 예약을 저장한 후에만 ‘예약됨’으로 표시됩니다. 당일 12시 이후 시작하면 다음 예약 시각부터 발송합니다.
  4. 잔고를 수정한 날에는 보고서 잔고 동기화를 눌러 서버의 보유 수량·매입가도 갱신하세요. 시세와 USDT/KRW 가격은 발송 시 서버가 새로 조회합니다.
  5. 언제든 발송 중지로 이후 발송을 멈출 수 있습니다. 이미 전송 중인 메시지는 취소되지 않을 수 있습니다.

알아두면 편한 점

  • 보고서용 잔고와 카카오 인증 정보는 본인의 비공개 서버 저장소에 보관됩니다. 공개 GitHub에는 코드만 올라갑니다. 거래 일지·메모는 서버에 보내지 않습니다.
  • 관리 키는 브라우저에 저장하지 않습니다. 다음 방문에서 예약을 바꾸거나 상태를 확인할 때 다시 입력하세요. 키를 입력하지 않아도 이미 서버에 저장된 예약은 계속 실행됩니다.
  • 보고서의 손익은 현재 보유분의 미실현 평가손익입니다. 원화 원가가 없는 보유분은 USDT 원가를 현재 환산합니다. XRP 보유액과 손익도 자산 합계에 포함합니다. XRP 신호는 참고용이며 기존 4종목의 목표 배분과 전략 성과에는 포함하지 않습니다.
  • 예약은 한국시간 12시에 실행되도록 설정되며 서비스 상태에 따라 지연될 수 있습니다. 가격이 지연되거나 인증에 문제가 있으면 발송을 보류하고 상태에 표시합니다.
  • 같은 날 중복 메시지를 막습니다. 전송 후 응답이 끊겨 성공 여부가 불분명한 경우에는 그날 자동 재발송하지 않습니다.
  • 카카오 연결을 해제했거나 인증 갱신이 실패하면 대시보드에서 카카오 연결을 다시 진행하세요.
